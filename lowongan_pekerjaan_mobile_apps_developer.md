# Lowongan Pekerjaan: Mobile Apps Developer

Kami sedang mencari seorang **Mobile Apps Developer** yang kreatif, solutif, dan berdedikasi untuk bergabung dengan tim kami. Anda akan bertanggung jawab merancang, membangun, serta memelihara aplikasi mobile (Android & iOS) yang responsif, berkinerja tinggi, dan memiliki *user experience* (UX) yang optimal.

## 📌 Deskripsi Pekerjaan

Sebagai Mobile Apps Developer, Anda akan bekerja sama dengan tim UI/UX Designer, Backend Developer, dan Product Manager untuk menghadirkan fitur-fitur baru serta memastikan performa aplikasi berjalan dengan lancar di berbagai perangkat mobile.

## 🛠 Tanggung Jawab Utama

* **Pengembangan Aplikasi:** Merancang, membangun, dan memelihara aplikasi mobile (iOS & Android) dari tahap konseptual hingga rilis di *store*.
* **Integrasi API:** Menghubungkan aplikasi mobile dengan *backend service* (RESTful API) dan layanan pihak ketiga (*third-party APIs*).
* **Implementasi UI/UX:** Mengubah desain UI/UX menjadi kode program yang responsif, intuitif, dan memiliki animasi yang mulus.
* **Testing & Debugging:** Melakukan pengujian (*unit testing*, *integration testing*), mengidentifikasi bug, serta mengoptimalkan performa dan penggunaan memori aplikasi.
* **Deployment & Maintenance:** Mengelola proses publikasi dan pembaruan (*update*) aplikasi di **Google Play Store** dan **Apple App Store**.
* **Kolaborasi Tim:** Bekerja sama secara aktif dengan lintas fungsi untuk memastikan integrasi fitur berjalan sesuai standar kualitas.

## 🎯 Kualifikasi & Persyaratan

### 1. Kualifikasi Umum

* Pendidikan minimal D3/S1 di bidang Teknik Informatika, Ilmu Komputer, Sistem Informasi, atau bidang terkait (atau pengalaman relevan setara).
* Pengalaman kerja **1 - 3 tahun** di bidang pengembangan aplikasi mobile (terbuka untuk *fresh graduate* yang memiliki portofolio aplikasi terpublikasi di Play Store / App Store).
* Memiliki portofolio aplikasi mobile yang dapat ditunjukkan atau diunduh langsung dari App Store / Play Store / GitHub.

### 2. Keterampilan Teknis (Hard Skills)

* **Framework & Bahasa Pemrograman:**
  * Menguasai salah satu *framework cross-platform* (contoh: **Flutter / Dart** atau **React Native / TypeScript**), *atau*
  * Menguasai pengembangan *native* (**Kotlin** untuk Android atau **Swift** untuk iOS).
* **State Management:** Memahami konsep *state management* dengan baik (seperti Provider / BLoC / Riverpod pada Flutter, atau Redux / Zustand / Context API pada React Native).
* **Integrasi API & Data:** Terbiasa mengonsumsi RESTful API, penanganan format JSON, penanganan sesi autentikasi (JWT / OAuth), serta penyimpanan data lokal (SQLite / Hive / Room / Realm).
* **Version Control:** Terbiasa menggunakan **Git** (GitHub / GitLab / Bitbucket) untuk kolaborasi tim.

### 3. Nilai Tambah (Nice-to-Have)

* Memahami integrasi *Push Notification* (Firebase Cloud Messaging / FCM) dan *Analytics* (Crashlytics, Sentry, Mixpanel).
* Memahami arsitektur aplikasi mobile yang bersih (*Clean Architecture*, MVVM).
* Memahami konsep **CI/CD** dan otomasi rilis untuk aplikasi mobile (Fastlane, Codemagic, GitHub Actions).
* Pengalaman mengintegrasikan *Payment Gateway* lokal atau internasional (Midtrans, Xendit, Stripe).
